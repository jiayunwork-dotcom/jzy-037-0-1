我手上有一批二元混合物的等温闪蒸工况要反复核算，希望有一个能常驻运行的相平衡计算服务替我把这件事做扎实。核算的对象是两组分体系在给定温度、压力下的汽液分配：给进料总组成、系统温度、系统压力，以及两个组分各自的饱和蒸汽压信息，服务解出汽化率（汽相摩尔占进料的比例）、液相组成、汽相组成，并判定体系当前处于两相、还是落在泡点以下或露点以上的单相区。

核算内核按理想溶液、理想汽相处理：每个组分的气液平衡常数等于该组分在系统温度下的饱和蒸汽压除以系统压力。汽化率由 Rachford-Rice 方程在开区间内求根确定，请在服务的说明里写清用的是二分还是牛顿迭代以及收敛判据，并全程只用这一套求解。饱和蒸汽压既支持按 Antoine 型关系（自然对数形式，含三个系数与温度）由温度算出，也允许调用方直接给两个组分的饱和蒸汽压绕过 Antoine，但无论哪种来源，平衡常数的定义都必须和闪蒸求解共用同一套组分下标，不允许闪蒸和蒸汽压各自维护一份彼此矛盾的组分顺序。当所有组分的平衡常数同时大于一或同时小于一时，说明工况落在两相区之外，服务要返回单相判定并给出所处一侧的理由，而不是硬解出一个假的汽化率。

对外通过 HTTP 提供服务。核算不是一问一答的即时接口，而是以「核算作业」为核心概念组织：调用方先提交一个作业，作业里带一个组分体系的物性定义（两组分的 Antoine 系数或直接给定的饱和蒸汽压、单位与参考约定）和一组待算工况点（每个点是一组温度、压力、进料组成）；服务受理后逐点求解并把每个点的结果连同该点是否两相、汽化率、液汽组成、各组分平衡常数一并落库，作业整体可查、可按作业号取回全部结果、也可只取其中某一工况点。物性定义作为可复用的登记项独立保存，多个作业可以引用同一份已登记的物性定义，也可以在提交作业时临时给出。请预置一份可手工核对的示范物性定义（戊烷、己烷量级的两组分体系），使得在其泡点附近提交的工况点，汽化率的符号与量级能与手算对得上。

非法输入要被稳妥拒绝并说明原因：温度、压力、进料组成里出现非正数，进料组成之和在容差外偏离一，Antoine 系数缺失或使分母为零，直接给定的饱和蒸汽压不为正，都要返回带类型的错误而非崩溃或返回近似解。核算结果要满足几条硬性关系并有自动化测试守住：收敛后液相组成之和与汽相组成之和都在容差内等于一；进料组成之和为一时物料衡算残差在容差内（每个组分的进料组成等于液相与汽相组成按汽化率的加权）；在温度与进料组成不变、仅升高压力时，同一体系的汽化率不得上升；工况逼近泡点时汽化率趋于零、逼近露点时趋于一，测试用逼近的方式检验而不是只断言「有解」。同一作业内不同工况点、不同作业之间的中间量各自独立累积，并发提交多个作业时彼此的结果不得互相覆盖或串号。

范围限定在二元等温闪蒸的相平衡核算，仅经 HTTP 对外提供作业提交、结果取回与物性定义登记，无需前端页面与账户体系，也不涉及精馏塔逐板计算。请用 Python 3.12 搭配 FastAPI 实现，选用一个持久化存储保存物性定义与作业结果，代码按职责拆分为多个模块（HTTP 路由、闪蒸求解内核、Antoine 与平衡常数、作业与物性定义的持久化各自独立成文件），并随附覆盖上述衡算闭合、单相判定、单调性与非法输入的自动化测试。交付时应能在容器中构建并起服务，用一份配置把服务与存储一起拉起对外可用。
